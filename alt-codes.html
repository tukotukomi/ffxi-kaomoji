Standard keys (Alt+0032–Alt+0126) aren't listed — those decimal codes just reproduce ordinary characters already on your keyboard (letters, digits, basic punctuation), so there's no need to use an Alt code for them.

Laptop users: if there's no dedicated numeric keypad, hold Fn to activate the embedded number pad (usually over J/K/L/U/I/O/7/8/9/M) before holding Alt.
