Alt Code Reference

Every standard Windows Alt+numpad character code — hold Alt, type the digits on the numeric keypad (Num Lock on), release. Works in nearly any Windows text field, including game chat windows.

Which table do I want? Use Windows (ANSI) codes — the Alt+0-prefixed ones — for accented letters, currency and punctuation; these are what reliably work in modern apps and games (e.g. typing ñ in Final Fantasy XI chat is Alt+0241). The Legacy (OEM/DOS) codes are the classic no-leading-zero combos from the old DOS character set — mostly symbols and box-drawing characters — and are less consistently supported outside older console apps.

FFXI-specific note: community testing (see footnote) confirms the entire Windows (ANSI) table — all of Alt+0128–Alt+0255 — renders correctly in FFXI's chat font. The Legacy (OEM/DOS) table is a different story: none of the classic picture symbols, card suits, arrows, box-drawing, or Greek-letter codes (Alt+1–31, Alt+127, and most of Alt+128–255) have been confirmed to render — FFXI's font appears to lack those glyphs entirely, so they'll typically show as ? or a small box in-game. Only a handful of OEM codes that happen to duplicate an ANSI letter/symbol — plus a few player-confirmed exceptions documented on the Face Builder page — are safe. When in doubt, stick to the ANSI table.

Standard keys (Alt+0032–Alt+0126) aren't listed — those decimal codes just reproduce ordinary characters already on your keyboard (letters, digits, basic punctuation), so there's no need to use an Alt code for them.

Laptop users: if there's no dedicated numeric keypad, hold Fn to activate the embedded number pad (usually over J/K/L/U/I/O/7/8/9/M) before holding Alt.
